# Chroniques d’Obsidienne

Jeu RPG idle en navigateur avec combat classique, équipement, talents, jardin et Donjon Mystère.

## Lancer le jeu

Ouvre `index.html` dans un navigateur moderne. Ce nom doit rester inchangé : GitHub Pages le reconnaît automatiquement comme page d’accueil.

## Structure active

- `index.html` : page d’entrée de Chroniques d’Obsidienne ;
- `dungeon-mystery.html` : interface du Donjon Mystère ;
- `isometric-garden.html` : jardin jouable ;
- `css/style.css` : interface principale ;
- `css/dungeon-mystery.css` : interface du Donjon Mystère ;
- `js/game.js` : jeu idle, équipement, talents et communication entre les modes ;
- `js/dungeon-mystery.js` : génération, exploration et combats du Donjon Mystère ;
- `assets/Dungeon_Mystere/` : tiles et objets utilisés par le Donjon Mystère ;
- `assets/sprites/` : personnages, monstres, jardin, cuisine et potions ;
- `docs/` : notes d’équilibrage et références de conception.

Les sauvegardes de partie sont stockées localement dans le navigateur.
