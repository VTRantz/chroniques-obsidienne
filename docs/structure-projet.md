# Structure du projet

Le dossier du jeu est nommé `chroniques-obsidienne`.

## Pages

- `index.html` charge le jeu principal.
- `dungeon-mystery.html` est chargé dans l’onglet Donjon.
- `isometric-garden.html` est chargé dans l’onglet Jardin.

## Code actif

- `js/game.js`
- `js/dungeon-mystery.js`
- le script intégré à `isometric-garden.html`

## Styles actifs

- `css/style.css`
- `css/dungeon-mystery.css`

## Règle importante

`index.html` est volontairement conservé sous ce nom pour fonctionner directement sur GitHub Pages.
