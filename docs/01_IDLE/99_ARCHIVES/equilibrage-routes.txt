ÉQUILIBRAGE DES ROUTES — CHRONIQUES D’OBSIDIENNE
=================================================

Règles communes
---------------
- Une route contient 10 combats ; le combat 10 est le boss.
- Une victoire soigne entièrement le héros.
- Une défaite renvoie à l’étape 1 de la route actuelle.
- Croissance par étape : PV ×1,09 et attaque ×1,055, appliquées avec
  `Math.pow(multiplier, étape - 1)`.
- Les routes peuvent posséder un renforcement tardif propre : il ne s’applique
  qu’aux étapes 5 à 9. Les quatre premières étapes et le boss conservent leur
  calcul normal ; le boss utilise son `bossVariant` propre.
- Les élites apparaissent à 5 % hors boss et utilisent le variant ×1,75.
- Le boss utilise le `bossVariant` propre à sa route.

Les trois boss avancés reçoivent un multiplicateur d'attaque ×0,875 : leurs

Objectifs de progression en Normal
-----------------------------------
- Le set précédent à +20 atteint en moyenne les étapes 4 à 6 de la route
  suivante, sans pouvoir tuer son boss.
- Le set principal à +10 atteint les étapes 7 à 9, avec très peu de victoires
  sur le boss.
- Le set principal à +20 donne environ 45 à 55 % de réussite sur le boss,
  sans talents de combat.
- Les talents restent une optimisation complémentaire, pas un raccourci qui
  remplace les améliorations d’équipement.
- Le soin complet entre les combats est conservé : le boss reste le principal
  test d’équipement de chaque route.

Hard et Hell
-------------
Les multiplicateurs Hard/Hell restent inchangés pour ce réglage. Ils devront
être simulés séparément après le rééquilibrage de l’essence, car ce dernier
détermine le temps réel nécessaire pour atteindre les rangs T2 et T3.

Difficultés globales conservées
-------------------------------
- Normal : PV ×1 ; attaque ×1 ; récompense ×1 ; or ×1 ; objets T1.
- Hard : PV ×6,2 ; attaque ×6,5 ; récompense ×4 ; or ×2,5 ; objets T2.
- Hell : PV ×18 ; attaque ×15 ; récompense ×12 ; or ×6 ; objets T3.

Rangs d’équipement conservés
-----------------------------
- T1 : statistiques ×1.
- T2 : statistiques ×2,2.
- T3 : statistiques ×4,5.

Les multiplicateurs Hard/Hell, les récompenses, les talents et les
statistiques de base des monstres n’ont pas été modifiés pendant ce réglage.
Les drops sont désormais liés au set de la route ; voir `monstres-et-drops.txt`.
