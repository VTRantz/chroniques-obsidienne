# Archive — Ancien système idle

Cette archive rassemble les documents utilisés avant la refonte complète du
mode idle décidée le 16 août 2026.

Les anciennes règles de combat, progression, talents, équipement, drops,
équilibrage et économie ne sont plus des règles actives. Elles sont conservées
uniquement comme historique et référence éventuelle.

Les noms utiles ont été recopiés dans `01_IDLE/REGLES_ACTUELLES.md` : héros,
monstres, objets et sets.
