# Décisions globales validées

- Le projet est organisé par systèmes : global, idle, jardin et Donjon Mystère.
- Les règles communes sont séparées des règles propres à chaque système.
- Le jardin est actuellement jouable mais incomplet.
- Le mode Idle est un système actif séparé, avec son propre combat, ses héros, ses routes et ses équipements.
- L’or idle et l’or du jardin doivent être reliés dans une évolution future.
