# Règles globales du projet

## Gestion documentaire

- Lire `00_INDEX.md` puis la mémoire globale et le dossier du système concerné.
- Une proposition ne devient pas une règle sans validation explicite.
- Chaque information doit avoir un emplacement principal unique.
- Les règles communes restent ici ; les règles propres à un système restent dans son dossier.
- Les archives ne servent pas de source active par défaut.

## Projet

- `Chroniques d’Obsidienne` est un RPG en pixel art développé d’abord pour navigateur.
- Le projet regroupe un mode idle, un jardin et un Donjon Mystère.
- Les systèmes peuvent partager certaines ressources, mais leurs règles internes restent séparées.

## Interactions communes

- Le héros est un élément partagé entre les systèmes lorsqu’une intégration est définie.
- La liaison entre l’or du mode idle et l’or du jardin est prévue, mais son fonctionnement détaillé reste à définir.
- Toute ressource partagée doit avoir une définition et une source de vérité clairement indiquées.
