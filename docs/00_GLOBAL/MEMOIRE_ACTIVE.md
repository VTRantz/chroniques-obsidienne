# Mémoire active globale

## État du projet

- Le jardin est jouable mais incomplet et est développé avec un développeur.
- Le mode Idle est jouable en 3v3 et fait l’objet d’itérations d’équilibrage et d’interface.
- Le Donjon Mystère est un système séparé dont les règles devront être documentées indépendamment.

## Interactions à surveiller

- Liaison future de l’or entre idle et jardin.
- Échanges éventuels de ressources entre les systèmes.
- Héros partagé entre les différents modes.

## Règle de contexte

Ne pas charger les règles détaillées des autres systèmes lorsqu’une tâche concerne
un seul mode, sauf si une interaction est explicitement étudiée.
