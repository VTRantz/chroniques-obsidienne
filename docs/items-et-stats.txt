CHRONIQUES D'OBSIDENNE — ITEMS, SETS ET STATS
==============================================

STATISTIQUES
------------
Puissance   : augmente les dégâts du héros.
Armure      : réduit les dégâts reçus et améliore la parade.
Vitalité    : augmente les PV maximum.
Critique    : chance d'infliger 70 % de dégâts supplémentaires.
Vitesse     : augmente l'esquive et la vitesse des combats.
Vol de vie  : rend un pourcentage des dégâts infligés.
Chance      : augmente le taux de drop total en mode Classique.

RÈGLE DE VITESSE
----------------
La vitesse de base est 1,00. Seule la partie au-dessus de 1,00 accélère le
combat : chaque +0,10 de vitesse donne exactement +1 % de vitesse de combat.

1,00 vitesse = +0 % combat
1,10 vitesse = +1 % combat
1,60 vitesse = +6 % combat
2,00 vitesse = +10 % combat

ESQUIVE ET PARADE
-----------------
Le héros commence avec 2 % d'esquive et 3 % de parade.
Chaque +0,10 de vitesse au-dessus de 1,00 ajoute +1 % d'esquive.
Chaque point d'armure ajoute +0,5 % de parade.
L'esquive et la parade sont toutes les deux limitées à 25 %.
Plafond : +50 % de vitesse de combat.

PALIERS D'ÉQUIPEMENT
--------------------
Normal donne des objets T1 : statistiques x1.
Hard donne des objets T2 : statistiques x2,2.
Hell donne des objets T3 : statistiques x3,8.
Chaque amélioration +1 ajoute +15 % aux statistiques de la pièce.
Un bonus de set complet utilise le palier le plus bas des six pièces.
