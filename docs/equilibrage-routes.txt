ÉQUILIBRAGE DES ROUTES — CHRONIQUES D’OBSIDIENNE
=================================================

Règles communes
---------------
- Une route contient 10 combats ; le combat 10 est le boss.
- Une victoire soigne entièrement le héros.
- Une défaite renvoie à l’étape 1 de la route actuelle.
- Croissance par étape : PV ×1,09 et attaque ×1,055, appliquées avec
  `Math.pow(multiplier, étape - 1)`.
- Les élites apparaissent à 5 % hors boss et utilisent le variant ×1,75.
- Le boss utilise le `bossVariant` propre à sa route.

Objectifs de progression en Normal
-----------------------------------
- Le set précédent à +10 permet de commencer la route suivante, mais ne doit
  pas suffire pour farmer confortablement son boss.
- Le set précédent à +20 donne environ 50 à 60 % de réussite contre le boss,
  sans talents de combat.
- Les talents de combat font monter ce palier autour de 80 à 93 %.
- Le set principal de la route à +10 rend ensuite le farm fiable.
- Le soin complet entre les combats est conservé : le boss reste le principal
  test d’équipement de chaque route.

Vérification des transitions Hard et Hell
------------------------------------------
- Entrée en Hard avec Archiliche T1 +20 : les quatre premières routes servent
  de transition ; le boss golem tombe environ une fois sur deux sans talents,
  puis la liche bloque la progression.
- Colosse de Granit T2 +20 : le golem Hard devient fiable, mais l’Archiliche
  Hard reste un vrai palier. Archiliche T2 +20 le rend fiable.
- Entrée en Hell avec Archiliche T2 +20 : progression fiable jusqu’aux golems,
  puis blocage sur l’Archiliche. Le passage aux pièces T3 est donc nécessaire.

Difficultés globales conservées
-------------------------------
- Normal : PV ×1 ; attaque ×1 ; récompense ×1 ; or ×1 ; objets T1.
- Hard : PV ×6,2 ; attaque ×6,5 ; récompense ×4 ; or ×2,5 ; objets T2.
- Hell : PV ×18 ; attaque ×15 ; récompense ×12 ; or ×6 ; objets T3.

Rangs d’équipement conservés
-----------------------------
- T1 : statistiques ×1.
- T2 : statistiques ×2,2.
- T3 : statistiques ×3,8.

Les multiplicateurs Hard/Hell, les récompenses, les drops, les talents et les
statistiques de base des monstres n’ont pas été modifiés pendant ce réglage.
